# pstack for Codex — alpha

This package adapts Lauren Tan's pstack workflows for Codex. It includes 58 skills; 57 have adapted instructions and `make-bot-ui` remains planning-only. Rendering and model-checking skills require the actual host tools named in their instructions; unavailable capabilities are not verified results.

Use `$poteto-help` for guidance, or `$poteto-mode` with your goal. Setup is optional. Most skills require explicit invocation; their availability depends on the host.

See the maintained [installation guide](https://github.com/Cusnd/pstack-codex/blob/main/docs/installation.md), [usage guide](https://github.com/Cusnd/pstack-codex/blob/main/docs/usage.md), and [verification limits](https://github.com/Cusnd/pstack-codex/blob/main/docs/verification.md). This ZIP is a source-only Agent Plugins 1.0 package; the documented Codex installation uses the Git marketplace.
